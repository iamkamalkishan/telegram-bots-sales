# Telegram Bots Sales Landing Page

Landing page for selling Telegram bots to businesses.

## Features

- Modern, responsive design
- Three bot products showcased
- Pricing information
- Testimonials section
- Call-to-action buttons

## Setup

1. Clone the repo
2. Edit `index.html` with your details
3. Deploy to GitHub Pages, Netlify, or any hosting

## Customization

- Change bot names, prices, features in `index.html`
- Add your support bot link
- Update testimonials with real reviews
